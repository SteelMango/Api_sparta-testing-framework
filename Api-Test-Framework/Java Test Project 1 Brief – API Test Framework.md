**Java** **Test** **Project** **1** **Brief –** **API** **Test** **Framework**

**Overview:**

You will be provided with a Docker image of an API system to test (SUT).  It will have Swagger documentation of the end points. Click [here](https://testingcircle.sharepoint.com/:u:/r/sites/SpartaGlobalHO/Shared%20Documents/Academy/Post-Academy%20Pathways/Java%20Test/SpartaAcademyApp.zip?csf=1&web=1&e=qi3hGN) to download the SUT and review the setup instructions in the README.

Create a Test Framework to ensure that the documented SUT RESTful services function as expected, both for happy and sad paths, and edge cases.

Create unit tests for any logic in your methods, using Mockito where necessary. 

Use GitHub Actions to automatically compile your code and run the unit tests whenever a pull request is made, and to automatically merge the code if the tests pass.  

**Project Components:**

**API Testing Framework:**

- Create a robust and extensible testing framework using Cucumber, RestAssured and JUnit for automated API tests

- Create parametrised tests with test data being fed in via an external file

**CI Pipeline Integration:**

- Create a CI pipeline using GitHub Actions for automated unit test execution on each pull request

**Defect Reports:**

- Document any defects found during testing, including steps to reproduce, severity, and status.

**Test Suite Results:**

- Generate and analyse test suite results, including pass/fail status

**GitHub repo** **containing** **all code, and a README File** **with** 

- Diagram(s) showing the framework architecture

- Detailed setup instructions and prerequisites

- User guide – how to run the tests

- Contribution guidelines for future testers.

**Project Management:**

- Project board with prioritised tasks and clearly defined test cases written in Gherkin syntax.

**Deliverables:**

**A 5-minute video** which explains what you did and what you learned in this project.  The target audience is a non-technical stakeholder.  

The video should include:

- Project board – how did you conduct the project?

- Overview of the test framework architecture and setup

- Quick look at BDD test scenarios written in Gherkin syntax

- Execution of automated API tests

- An overview of unit tests written of the framework

- Demonstration of the CI pipeline

**Documentation Package:**

- The README for your automated test project, exported as a .pdf document

- The user stories created

- Test results and Test Suite Results

- Defect Reports

- A report of unit testing performed, including code coverage metrics.

- **Docker:**  For running the SUT
